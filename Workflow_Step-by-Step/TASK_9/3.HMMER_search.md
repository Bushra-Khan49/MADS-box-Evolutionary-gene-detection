# Step 3: Run HMMER search

## **Aim**: To identify MADS and K-domain proteins (using Pfam-calibrated HMM profiles sourced from UniProt/InterPro).

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```
---

## Execute HMMER Search:

### Step 3.0: Perform hmmsearch for MADS and K-domain using Pfam profiles (Sourced from UniProt/InterPro)
```bash
# Identify MADS-box domains in Helianthus annuus
hmmsearch --tblout helianthus_annuus_MADS_hits.txt PF00319.MADS.hmm helianthus_annuus.protein.fa
# Identify K-box domains in Helianthus annuus
hmmsearch --tblout helianthus_annuus_K_hits.txt PF01486.K_domain.hmm helianthus_annuus.protein.fa
```

### Step 3.1: Merge MADS and K_domain results

#### Merge Domain Results:
```bash
# Combine MADS domain results with K-box domain results for Helianthus annuus
```

### Step 3.2: Shortlist candidates (Combining BLAST and HMMER)
