# <h2 style="color:darkblue; font:Times New Roman;">Phase 2: Identification & Selection Interaction — Step 02</h2> 
<br>

## **Aim**  
To enforce absolute biological stringency by performing a **Symmetrical Selection Interaction** between similarity-based results (Phase 1) and domain-based results (Phase 2). Only candidate IDs that satisfy both criteria are promoted as true evolutionary counterparts.
<br>

## Steps:-

```bash
#!/bin/bash
```

> ### Step 1: Comparative Intersection Analysis
Compare the list of orthologous candidates mapped back to Arabidopsis (from the Phase 1 BLAST search) with the list of domain-validated candidates identified via HMMER. 

**Selection Rule:** Only candidate IDs found in BOTH sets are promoted. This dual-verification eliminates:
1. **False Positives (BLAST)**: Hits with high similarity but missing critical functional domains.
2. **Structural Outliers (HMMER)**: Sequences with correct domains but no verifiable orthology to the Arabidopsis anchor set.

```bash
# Example intersection logic using 'comm' or 'grep' to find common IDs
cd /Users/bushrakhan/Desktop/NIPGR-data/NIPGR_WORK/Phase_2_Workspace
sort ../Phase_1_Orthology_and_Filtering/Arabidopsis_Mapped_IDs.txt > blast_sorted.txt
sort ../Phase_2_Identification_and_Selection/HMMER_Confirmed_IDs.txt > hmmer_sorted.txt

comm -12 blast_sorted.txt hmmer_sorted.txt > Intersection_Final_Candidates.txt
```

> ### Step 2: Extract Integrated Candidate Set
Using the intersection list, pull the full protein sequences to generate the high-confidence species dataset.

```bash
# Pull finalized sequences for the sequential alignment
seqtk subseq Proteomes/AmbTr.fa Intersection_Final_Candidates.txt > Final_Verified_Candidates.fa
```

*(This "Selection Interaction" ensures that every sequence in your tree is both structurally valid and evolutionarily relevant!)*
