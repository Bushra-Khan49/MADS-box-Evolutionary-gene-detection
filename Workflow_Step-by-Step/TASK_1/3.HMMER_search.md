# Step 3: Run HMMER search (Arabidopsis Anchor Set)

## **Aim**: To validate MADS and K-domain proteins in *Arabidopsis thaliana* using Pfam-calibrated HMM profiles to establish a high-confidence phylogenetic anchor set.

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/MADS-box-Evolutionary-gene-detection
```

---

## Execute HMMER Search:

### Step 3.0: Perform hmmsearch for MADS and K-domains
```bash
# Identify MADS-box domains in Arabidopsis thaliana (TAIR10)
hmmsearch --tblout Arabidopsis_MADS_hmmsearch.txt PF00319.MADS.hmm TAIR10_pep_20101214.fa

# Identify K-domains in Arabidopsis thaliana (TAIR10)
hmmsearch --tblout Arabidopsis_K_domain_hmmsearch.txt PF01486.K_domain.hmm TAIR10_pep_20101214.fa
```

### Step 3.1: Perform Domain Intersection
To ensure candidates are high-confidence MIKCc-type genes, we identify sequences containing **both** the MADS-box and the K-domain.

```bash
# Extract IDs from both searches and find the intersection
grep -v "^#" Arabidopsis_MADS_hmmsearch.txt | awk '{print $1}' > mads_ids.txt
grep -v "^#" Arabidopsis_K_domain_hmmsearch.txt | awk '{print $1}' > kdomain_ids.txt

# Find common IDs (Intersection)
comm -12 <(sort mads_ids.txt) <(sort kdomain_ids.txt) > MADS_Kdomain_intersection.txt
```
