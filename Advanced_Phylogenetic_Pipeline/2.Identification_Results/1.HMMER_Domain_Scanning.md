# <h2 style="color:darkblue; font:Times New Roman;">Phase 2: Identification & Selection Interaction — Step 01</h2> 
<br>

## **Aim**  
To construct the local directory environment for Phase 1 and organize the raw genome datasets retrieved from Phase 0 into a streamlined programmatic working directory. 

This prevents cluttering the initial database folder and safeguards the original downloads.
<br>

## Steps:-

> ### Step 0: Construct Working Directories
We must first build the sandbox environment natively inside our NIPGR working directory.
```bash
cd /Users/bushrakhan/Desktop/NIPGR-data/NIPGR_WORK
mkdir -p Phase_1_Workspace
cd Phase_1_Workspace

mkdir -p Genomes Proteomes Annotations
```

> ### Step 1: Copy Original Genomes & Proteomes
Copy Phase 0 downloaded datasets carefully into this working repository. This ensures if any script destructively parses sequences, our original datasets generated from `TASK_0` remain unharmed.
```bash
# Example syntax to securely copy the standardized species arrays
cp -r ../data/genomes/* Genomes/
cp -r ../data/proteomes/* Proteomes/
cp -r ../data/annotations/* Annotations/
```

> ### Step 2: Establish the Arabidopsis Reference System
Copy TAIR10 files out of the baseline datasets directly here. We isolate *A. thaliana* separately from the structural genomic loops because it serves as the coordinate system rather than an identification target.
```bash
cp ../data/proteomes/Arabidopsis_TAIR10_proteins.fa .
mv Arabidopsis_TAIR10_proteins.fa Reference_Arabidopsis.fa
```

> ### Step 3: Symmetrical Selection Interaction (Intersection)
To enforce absolute biological stringency, we perform a **Comparative Intersection Analysis**. We compare the list of orthologous candidates mapped back to Arabidopsis (from **Phase 1**) with the list of domain-validated candidates identified via HMMER (from **Phase 2**). 

**Only candidate IDs found in BOTH sets** are promoted for subsequent evolutionary analysis. This dual-verification eliminates false positives and sequences that lack either similarity or structural integrity.

```bash
# Intersect BLAST (Phase 1) and HMMER (Phase 2) result IDs
comm -12 <(sort Phase_1_IDs.txt) <(sort Phase_2_IDs.txt) > Final_HighConfidence_Candidates.txt
```
