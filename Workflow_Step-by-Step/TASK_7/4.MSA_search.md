# Step 4: Multiple Sequence Alignment (MSA)

## **Aim**: To align identified candidate MADS-box protein sequences using MAFFT, MUSCLE, and Clustal Omega for comparative phylogenetic analysis.

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```

### Combine files for MSA:
```bash
# Merge query and candidates into one file for alignment
cat At_ABCDE_QUERY.fa Shortlisted_candidates.txt > medicago_truncatula_combined_for_msa.fa
```

### Run Alignments:

#### 1. MAFFT (Primary)
```bash
mafft --auto medicago_truncatula_combined_for_msa.fa > medicago_truncatula_MAFFT_Results.fa
```

#### 2. MUSCLE (Secondary)
```bash
muscle -in medicago_truncatula_combined_for_msa.fa -out medicago_truncatula_MUSCLE_Results.fa

#### 3. Clustal Omega (Tertiary)
```bash
clustalo -i medicago_truncatula_combined_for_msa.fa -o medicago_truncatula_ClustalO_Results.fa
```
