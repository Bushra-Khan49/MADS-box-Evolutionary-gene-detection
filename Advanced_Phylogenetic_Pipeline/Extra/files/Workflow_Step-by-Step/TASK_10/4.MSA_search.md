# Step 4: Multiple Sequence Alignment (MSA)

## **Aim**: To align identified candidate MADS-box protein sequences using MAFFT, MUSCLE, and Clustal Omega for comparative phylogenetic analysis.

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```

### Combine files for MSA:
```bash
# Merge query and candidates into one file for alignment
cat At_ABCDE_QUERY.fa Shortlisted_candidates.txt > nelumbo_nucifera_combined_for_msa.fa
```

### Run Alignments:

#### 1. MAFFT (Primary)
```bash
mafft --auto nelumbo_nucifera_combined_for_msa.fa > nelumbo_nucifera_MAFFT_Results.fa
```

#### 2. MUSCLE (Secondary)
```bash
muscle -in nelumbo_nucifera_combined_for_msa.fa -out nelumbo_nucifera_MUSCLE_Results.fa
```

#### 3. Clustal Omega (Tertiary)
```bash
clustalo -i nelumbo_nucifera_combined_for_msa.fa -o nelumbo_nucifera_ClustalO_Results.fa
```
