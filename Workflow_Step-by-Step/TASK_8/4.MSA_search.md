# Step 4: Multiple Sequence Alignment (MSA)

## **Aim**: To align identified candidate MADS-box protein sequences using MAFFT, MUSCLE, and Clustal Omega for comparative phylogenetic analysis.

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```

### Combine files for MSA:
```bash
# Merge query and candidates into one file for alignment
cat At_ABCDE_QUERY.fa Shortlisted_candidates.txt > prunus_persica_combined_for_msa.fa
```

### Run Alignments:

#### 1. MAFFT (Primary)
```bash
mafft --auto prunus_persica_combined_for_msa.fa > prunus_persica_MAFFT_Results.fa
```

#### 2. MUSCLE (Secondary)
```bash
muscle -in prunus_persica_combined_for_msa.fa -out prunus_persica_MUSCLE_Results.fa
```

#### 3. Clustal Omega (Tertiary)
```bash
clustalo -i prunus_persica_combined_for_msa.fa -o prunus_persica_ClustalO_Results.fa
```
