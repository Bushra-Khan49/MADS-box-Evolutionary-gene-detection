# Step 4: Multiple Sequence Alignment (MSA)

## **Aim**: To align identified candidate MADS-box protein sequences using MAFFT, MUSCLE, and Clustal Omega for comparative phylogenetic analysis.

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```

### Combine files for MSA:
```bash
# Merge query and candidates into one file for alignment
cat At_ABCDE_QUERY.fa Shortlisted_candidates.txt > amborella_trichopoda_combined_for_msa.fa
```

### Run Alignments:

#### 1. MAFFT (Primary)
```bash
mafft --auto amborella_trichopoda_combined_for_msa.fa > amborella_trichopoda_MAFFT_Results.fa
```

#### 2. MUSCLE (Secondary)
```bash
muscle -in amborella_trichopoda_combined_for_msa.fa -out amborella_trichopoda_MUSCLE_Results.fa
```

#### 3. Clustal Omega (Tertiary)
```bash
clustalo -i amborella_trichopoda_combined_for_msa.fa -o amborella_trichopoda_ClustalO_Results.fa
```
