# Step 3: Run HMMER search

## **Aim**:  To identify MADS and K-domain proteins (using Pfam-calibrated HMM profiles sourced from UniProt/InterPro).

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```
---

## Execute HMMER Search:


### Step 3.0: Perform hmmsearch for MADS and K-domain using Pfam profiles (Sourced from UniProt/InterPro)
```bash
# Identify MADS-box domains
hmmsearch --tblout {species}_MADS_hits.txt PF00319.MADS.hmm {species}.fa
# Identify K-box domains
hmmsearch --tblout {species}_K_hits.txt PF01486.K_domain.hmm {species}.fa

# Example
hmmsearch --tblout Oryza_sativa_MADS_hmmsearch_results.txt PF00319.MADS.hmm Oryza_sativa.fa
hmmsearch --tblout Oryza_sativa_K_domain_hmmsearch_results.txt PF01486.K_domain.hmm Oryza_sativa.fa
```

### Step 3.1: Merge MADS and K_domain results

#### Merge Domain Results:
```bash
# Combine MADS domain results with K-box domain results
cd ~/Desktop/NIPGR-data/HMMER_project
cat {species_fa}_MADS_hmmsearch_results.txt {species_fa}_K_domain_hmmsearch_results.txt > Combined_hmmsearch_results(MADS+K_domain).txt

# Example
cd ~/Desktop/NIPGR-data/HMMER_project
cat Oryza_sativa_MADS_hmmsearch_results.txt Oryza_sativa_K_domain_hmmsearch_results.txt > Combined_hmmsearch_results(MADS+K_domain).txt

```
