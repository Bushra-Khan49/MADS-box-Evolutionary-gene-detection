## **Aim**  
Perform mathematically precise alignments scaling both sequence divergence globally across the **Strict 45 Arabidopsis Anchors** and target species locally. This step executes a **Sequential MSA** for all species individually using the high-confidence candidates derived from the selection interaction.

The alignment specifically relies on M and K domain conservation to generate proper structural overlap while computing sequence gap logic strictly through MAFFT or MUSCLE.  
<br>

## Steps:-

```bash
#!/bin/bash
```

> ### Step 0: File Consolidation (Strict 45 Anchors)
It is critical that the alignments occur *co-dependently*. We concatenate the finalists of our species with the **45 Strict Arabidopsis MIKCc Anchors** (the domain-verified gold standard identified in Phase 0).
```bash
cd /Users/bushrakhan/Desktop/NIPGR-data/NIPGR_WORK/MSA
mkdir -p Species_Specific_MSA

# Concatenate finalized candidates with the 45 Strict AT Anchors
cat ../Final_Shared_Candidates/AmbTr_Verified.fa ../Reference_Anchors/Arabidopsis_Strict_MIKCc_45.fa > Combined_AmbTr_AT_Strict45.fa
```

> ### Step 1: Execute Parameterized Sequence Alignment
We apply algorithms to ensure precision around the highly-conserved 'M' (MADS) and 'K' (Keratin-like) domains. We will permit generous gaps in the inherently variable 'I' and 'C' regions.
```bash
# Example showing an sequential MAFFT run:
mafft --maxiterate 1000 --localpair Combined_AmbTr_AT_Strict45.fa > Aligned_AmbTr_AT_Strict45.fa
```
