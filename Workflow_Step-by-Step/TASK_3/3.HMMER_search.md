# Step 3: Run HMMER search

## **Aim**: To identify MADS and K-domain proteins (using Pfam-calibrated HMM profiles sourced from UniProt/InterPro).

---

## Procedure :-

### Navigate to Project Directory:
```bash
cd ~/Desktop/NIPGR-data/HMMER_project
```
---

## Execute HMMER Search:

### Step 3.0: Perform hmmsearch for MADS and K-domain using Pfam profiles (Sourced from UniProt/InterPro)
```bash
# Identify MADS-box domains in Nymphaea colorata
hmmsearch --tblout nymphaea_colorata_MADS_hits.txt PF00319.MADS.hmm nymphaea_colorata.protein.fa
# Identify K-box domains in Nymphaea colorata
hmmsearch --tblout nymphaea_colorata_K_hits.txt PF01486.K_domain.hmm nymphaea_colorata.protein.fa
```

### Step 3.1: Merge MADS and K_domain results

#### Merge Domain Results:
```bash
# Combine MADS domain results with K-box domain results for Nymphaea colorata
cat nymphaea_colorata_MADS_hits.txt nymphaea_colorata_K_hits.txt > Combined_hmmsearch_results(MADS+K_domain).txt
```
--- 

### Step 3.2: Shortlist candidates (Combining BLAST and HMMER)

#### Combine finalists from blast and domain searches
```bash
# Combine HMMER domain results with BLAST similarity results
cat Combined_hmmsearch_results\(MADS+K_domain\).txt ../BLAST_project/nymphaea_colorata_Blast_results.txt > Shortlisted_candidates.txt
```

#### Shortlisted candidates

```bash
head -n 30 Shortlisted_candidates.txt
```
